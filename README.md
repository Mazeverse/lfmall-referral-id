# LF몰 추천인 아이디 안내

추천인 아이디: `21kwon`

## Cloudflare Pages 배포
1. GitHub 저장소 `lfmall-referral-id`를 생성합니다.
2. 이 폴더의 `index.html`, `robots.txt`를 저장소 루트에 업로드합니다.
3. Cloudflare Workers & Pages → Create application → Pages → Connect to Git → 저장소 선택.
4. Framework preset: None, Build command: 비워두기, Build output directory: `/`.
5. 배포 후 실제 URL을 확인하고 Google Search Console에 등록합니다.

주의: 현재 LF몰 추천인 기능과 혜택 운영 여부는 공식 페이지에서 확인해야 합니다.
